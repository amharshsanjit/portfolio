## 💻 How to Run Locally

### 1. Prerequisites
Ensure you have **Node.js** (v18.0.0 or later) installed on your system.
Verify via terminal:
```bash
node -v
npm -v
```

### 2. Install Dependencies
Open a terminal in the project directory:
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
The website will launch at `http://localhost:3000` (or `http://localhost:5173`).

### 4. Build for Production
To create an optimized production build:
```bash
npm run build
```
To preview the production build locally:
```bash
npm run preview
```

## ☁️ How to Deploy for Free on Vercel

You can deploy this portfolio for free on Vercel in less than 2 minutes using either method below:

### Method A: Deploy via GitHub (Recommended)

1. **Push your code to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of Harsh Sanjit portfolio"
   git branch -M main
   git remote add origin https://github.com/amharshsanjit/portfolio.git
   git push -u origin main
   ```
2. **Go to Vercel**:
   - Visit [https://vercel.com](https://vercel.com) and log in with your GitHub account.
3. **Import Project**:
   - Click **"Add New..."** ➔ **"Project"**.
   - Select your repository (`portfolio`).
4. **Configure Settings**:
   - Framework Preset: **Vite** (Vercel automatically detects this).
   - Root Directory: `./`
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. **Click Deploy**:
   - Vercel will build and assign you a free live URL (e.g., `harsh-sanjit.vercel.app`).

### Method B: Deploy via Vercel CLI

1. Install the Vercel CLI globally:
   ```bash
   npm i -g vercel
   ```
2. In the project folder, run:
   ```bash
   vercel
   ```
3. Follow the quick prompts in your terminal:
   - Set up and deploy? **Y**
   - Which scope? Select your personal account
   - Link to existing project? **N**
   - Project name? `harsh-sanjit-portfolio`
   - Directory located? `./`
4. For production deployment:
   ```bash
   vercel --prod
   ```

### 🌐 Connecting your custom domain (`harshsanjit.dev`)

1. Open your project on the Vercel Dashboard.
2. Go to **Settings** ➔ **Domains**.
3. Add `harshsanjit.dev` and `www.harshsanjit.dev`.
4. Add the DNS records (A record or CNAME) shown by Vercel into your domain registrar (Namecheap, GoDaddy, Cloudflare, etc.).
5. Vercel automatically issues and renews a free **SSL certificate (HTTPS)**.
